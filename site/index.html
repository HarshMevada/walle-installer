Wake up Wall-E.

Installs the Wall-E firmware on a Seeed XIAO ESP32-S3 Sense straight from your browser. No software to install.

This browser can't flash devices. Open this page in Chrome or Edge on a computer. Open this page over https (the github.io link) to allow USB access.

Use a USB data cable. If no port shows up: hold BOOT, tap RESET, release BOOT, and try again. Choose the port called “USB JTAG/serial debug unit”. Installing erases the saved Wi-Fi.

Hardware tests (one part at a time)

Use these when something doesn't work. Each test is a tiny program that checks one part only. Install a test, then in the same window click Logs & Console to read what it reports. When all four pass, install the Wall-E firmware above again.
TEST 1
Screen (OLED)

SDA → D4 · SCL → D10 · VCC → 3V3

PASS: the log shows "Found device at 0x3C" and the screen shows text and blinking eyes.

Use Chrome or Edge on a computer. Open this page over https.
TEST 2
Motors (TB6612)

AIN1 → D3 · AIN2 → D6 · BIN1 → D7 · BIN2 → D2 · PWMA + PWMB → D9 · STBY → 3V3. Lift the robot first!

PASS: each wheel turns as the log describes: left fwd/back, right fwd/back, both, spin.

Use Chrome or Edge on a computer. Open this page over https.
TEST 3
Speaker (MAX98357)

BCLK → D0 · LRC → D1 · DIN → D5 · VIN → 5V

PASS: three beeps (low, mid, high) and a short melody, repeating.

Use Chrome or Edge on a computer. Open this page over https.
TEST 4
Microphone (built-in)

Sense expansion board attached · nothing wired to D11/D12

PASS: the level number stays low when quiet and jumps when you talk or clap.

Use Chrome or Edge on a computer. Open this page over https.

The Arduino IDE versions of these tests are in the tests folder on GitHub.

After installing

01
Connect Wi-Fi Join the Xiaozhi-XXXX hotspot from your phone, pick your 2.4 GHz Wi-Fi and enter the password.
02
Activate Wall-E shows a 6-digit code. Enter it at xiaozhi.me → Add device.
03
Make it Wall-E In the xiaozhi.me console set the name Wall-E, a voice, and a short character description. Then say “Hi ESP”!

Try saying

“Move forward for one second”drives the tank treads
“Turn left” / “Stop”spins in place, eyes follow
“What do you see?”takes a photo and describes it
